About countries
Version: 1.0
Author: Piotr Mludzik 🇵🇱
About Countries is a web application designed to provide an interactive and visually appealing exploration of country-specific data. It allows users to access detailed information, compare metrics, and analyze global data seamlessly. The application leverages the Rest Countries API . Comprehensive country data, including population, region, and flags. Detailed views with metrics such as area, time zones, currencies, and neighbors. Search, filter, and side-by-side country comparisons for enhanced usability. This application is open-source and distributed under the MIT License . The source code for this project can be found here: About Countries on GitHub .
